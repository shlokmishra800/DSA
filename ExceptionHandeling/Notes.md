# Exception Handling in Java

## Definition

Exception Handling is a mechanism in Java that allows a program to handle runtime errors gracefully without terminating unexpectedly. It helps maintain the normal flow of the program even when errors occur.

## Explanation

- An exception is an event that disrupts the normal execution of a program.
- Exception handling enables developers to detect and manage errors effectively.
- It prevents abrupt program termination.
- Java provides built-in classes and keywords to handle exceptions.
- Exception handling improves the reliability and robustness of applications.

---

# Why Exception Handling is Needed

## Definition

Exception handling is used to manage runtime errors so that the program can continue executing normally.

## Benefits

1. Prevents program crashes.
2. Maintains normal program flow.
3. Improves code readability and maintainability.
4. Separates error-handling code from regular code.
5. Makes applications more reliable.

---

# Types of Exceptions

## Checked Exceptions

### Definition

Checked exceptions are exceptions that are checked by the compiler at compile time.

### Explanation

- Must be handled using `try-catch` or declared using `throws`.
- Occur due to external factors such as file handling or database access.

### Examples

- IOException
- SQLException
- FileNotFoundException

---

## Unchecked Exceptions

### Definition

Unchecked exceptions are exceptions that occur during program execution and are not checked by the compiler.

### Explanation

- Occur because of programming errors.
- Handling them is optional.

### Examples

- ArithmeticException
- NullPointerException
- ArrayIndexOutOfBoundsException

---

# Important Keywords in Exception Handling

## try

### Definition

The `try` block contains code that may generate an exception.

### Explanation

- Java monitors the code inside the try block.
- If an exception occurs, control transfers to the catch block.

---

## catch

### Definition

The `catch` block handles exceptions generated by the try block.

### Explanation

- Executes only when an exception occurs.
- Prevents abnormal termination of the program.

---

## finally

### Definition

The `finally` block contains code that always executes, whether an exception occurs or not.

### Explanation

- Commonly used for resource cleanup.
- Executes after try and catch blocks.

---

## throw

### Definition

The `throw` keyword is used to explicitly create and throw an exception.

### Explanation

- Allows programmers to generate custom exceptions.
- Transfers control to the nearest exception handler.

---

## throws

### Definition

The `throws` keyword declares exceptions that a method may generate.

### Explanation

- Used in method declarations.
- Informs the caller about possible exceptions.

---

# Exception Hierarchy in Java

## Definition

All exception classes in Java are derived from the `Throwable` class.

# Advantages of Exception Handling
