# Functions in Java

## Definition
A **Function** (also called a **Method** in Java) is a block of code that performs a specific task.  
It helps break down complex problems into smaller, reusable pieces.

---

## Explanation
Functions improve **modularity**, **reusability**, and **readability** of code.  
In Java, every function must be defined inside a class.

### Structure of a Function:
```java
returnType functionName(parameters) {
    // body of the function
    return value; // optional
}

### Types of Functions
-## Built-in Functions
Predefined methods provided by Java libraries.
Example: Math.max(10, 20)
- ## User-defined Functions
Functions created by the programmer to solve specific problems.
Example: int factorial(int n)
- ## Recursive Functions
Functions that call themselves to solve problems step by step.
